# 投稿データの書き方（posts/YYYY-MM-DD.json）

日曜以外（月〜土）は、毎朝の投稿セットを作るときに、このファイルも作って `main` に push する。
GitHub Actions が 8:00・9:30（昼の投稿）と 15:00・16:30（夜の投稿）にファイルを見つけ、表現チェック → 画像づくり → 承認 → 予定時刻に投稿、の順で進める。

```json
{
  "date": "2026-10-27",
  "type": "carousel",
  "post_at": "12:00",
  "caption": "キャプション本文（改行は \\n）。最後にコメントの呼びかけとハッシュタグ5個",
  "brand": "あいの大人の美容ノート",
  "slides": [
    {"type": "cover", "kicker": "成分のはなし vol.2", "title": "1枚目の大見出し\\n*強調したい言葉*\\nって？", "sub": "30代からの成分えらび"},
    {"type": "body", "num": "01", "title": "見出し", "text": "本文。\\n**黄色マーカーで強調**も使える", "note": "※補足（任意）"},
    {"type": "body", "num": "02", "title": "...", "text": "..."},
    {"type": "cta", "lead": "前置きの一言", "title": "気になる方は\\nコメントで", "keyword": "成分", "small": "と送ってくださいね", "footer": "フォローしてね"}
  ]
}
```

## ルール

- `type` は `carousel` のときだけ自動投稿する
- `post_at` は日本時間。月・水・金は `21:00`、火・木は `12:00`、土は `10:00`
- スライドは 4〜7 枚。1枚目は `cover`、最後は `cta`、間は `body`
- 1枚あたりの文字は少なめに（`body` の `text` は 5 行・1行 18 文字くらいまで）
- `title` は 1行 8〜9 文字・3行以内（`cover` は大きい文字なので特に短く）
- `*…*` は表紙の見出しの強調（ローズ色＋黄色マーカー）、`**…**` は本文の強調
- 【】のプレースホルダーや未確認の数字は入れない（画像にそのまま出てしまうため）
- 化粧品として使えない表現は `scripts/daily.py` の NG リストで自動チェックされ、見つかると投稿が止まる
- `status` などは Actions が書き込むので、作るときは入れない
